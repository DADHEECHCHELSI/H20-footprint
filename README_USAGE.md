## 🔍 **HOW SCORING WORKS**

### Calculation Method
```
Total Water Footprint = Direct Water + Virtual Water

Direct = Bathing + Toilet + Laundry + Kitchen + Cleaning + Leaks
Virtual = Diet + Clothing + Electricity + Digital
```

### Score Bands

| Score | Band | Meaning | Status |
|-------|------|---------|--------|
| 1-2 | Green | Very efficient | ⭐ Excellent |
| 2-4 | Green | Efficient | ✅ Good |
| 4-5 | Yellow | Moderate | 📊 Average |
| 5-8 | Orange | High | ⚠️ Room to improve |
| 8-9 | Red | Very high | 🔴 Urgent action |
| 9-10 | Red | Excessive | 🔴 Critical |

### Reference Points

```
Score 1 = ~50 L/day (Sustainable)
Score 4 = ~135 L/day (India urban standard)
Score 6 = ~500 L/day (Moderate lifestyle)
Score 8 = ~1,000 L/day (High consumption)
Score 10 = ~2,000+ L/day (Excessive)

Global Average Score: ~6 (2,000-2,500 L/day)
India Average Score: ~4 (1,200-1,500 L/day)
Recommended Target: 2-3 (600-1,000 L/day)
```

## 💡 **USING YOUR RESULTS**

### If Score ≤ 4 (Green - In the Green)
**What this means**: You're efficient! 
- Household water use is below India's standard
- Combined lifestyle is conservative
- **Action**: Maintain habits, help others

**Suggested next steps**:
1. Share your tips with 3 people
2. Monthly leak checks
3. Check if any aging appliances need upgrading

### If Score 4-8 (Yellow/Orange - Room to Improve)
**What this means**: Moderate usage, improvements possible
- Likely at or above India's urban standard
- Some easy wins available
- **Action**: Target top 2-3 changes

**Quick wins** (each saves 20-60 L/day):
1. Fix any leaks (check today!)
2. Shorten showers to 5 minutes
3. Reduce meat to 1-2x/week
4. Wash dishes with basin instead of tap
5. Full-load laundry only

### If Score > 8 (Red - High/Excessive)
**What this means**: Significant consumption
- Well above India's standard
- Multiple changes recommended
- **Action**: Implement 4-5 changes systematically

**Priority actions** (each saves 30-100 L/day):
1. **FIX LEAKS IMMEDIATELY** (biggest impact)
2. Reduce shower time (15+ min → 5 min)
3. Check toilet for running/leak
4. Reduce meat significantly (3-5x/week → 1x/week)
5. Use washing machine for clothes only
6. Install dual-flush or use bucket system
7. Reduce AC usage or upgrade to efficient model

## 🔧 **TROUBLESHOOTING**

### Survey Won't Load
- Ensure JavaScript is enabled
- Try different browser
- Check file location (open from computer, not email)
- Clear browser cache

### Buttons Not Responding
- Wait 1-2 seconds (animations may overlap)
- Click exactly on button text
- Check browser zoom level (try 100%)

### Progress Not Saving
- Note: Progress resets on page reload (by design)
- Retaking survey overwrites previous answers
- Results can be screenshotted to save

### Mobile Issues
- Portrait mode: Use landscape for best experience
- Zoom: Set to 100% for touch precision
- Slower phones: Wait for animations to complete
